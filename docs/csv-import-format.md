# QQ 同步助手 CSV 导入格式说明

## 概述

Universal PIM 支持导入 QQ 同步助手导出的短信 CSV 文件。

## CSV 格式

### 表头

CSV 文件必须包含以下表头（顺序不重要）：

| 字段名 | 说明 | 必需 |
|--------|------|------|
| `内容` | 短信内容 | ✅ |
| `对方名字` | 联系人名称（可选，用于显示） | ❌ |
| `对方手机` | 电话号码 | ✅ |
| `发送时间` | 时间戳，格式 `YYYY/MM/DD HH:MM:SS` | ✅ |
| `类型` | 消息类型：`收件箱` 或 `发件箱` | ❌ |

### 示例

```csv
"内容","对方名字","对方手机","发送时间 ","类型 "
"【限时专属礼遇—刷卡赚固额】报名当日起至12月15日...","95555","95555","2016/11/01 14:23:02","收件箱",
"【浦发信用卡中心】感谢您的支持...","1069040088788","1069040088788","2016/11/01 10:39:07","收件箱",
"【浦发信用卡中心】感谢您的支持...","1069040088788","1069040088788","2016/11/01 10:32:57","收件箱",
```

### 格式说明

1. **编码**：UTF-8 编码
2. **分隔符**：逗号 `,`
3. **引号**：字段用双引号 `"` 包裹，内容中的引号用 `""` 转义
4. **换行**：每行一条记录，以换行符分隔
5. **结尾**：每行以逗号 `,` 结尾（QQ 同步助手格式特点）

## 校验规则

导入时会逐行校验，以下情况会导致记录被跳过：

1. **表头包含未知字段** — 只允许上述 5 个字段，任何额外字段会导致整个文件无法导入
2. **内容为空** — `内容` 字段不能为空
3. **对方手机为空** — `对方手机` 字段不能为空
4. **发送时间为空** — `发送时间` 字段不能为空
5. **时间格式不正确** — 必须是 `YYYY/MM/DD HH:MM:SS` 格式
6. **时间无效** — 如 2016/13/45 这样的无效日期

## 导入行为

- **渠道**：所有导入的消息自动归类为「短信」渠道
- **方向**：根据 `类型` 字段判断（`发件箱` 为发送，其他为接收）
- **联系人**：`对方手机` 字段作为联系人名称显示
- **ID 生成**：使用 `csv_时间戳_行号` 作为内部 ID
- **去重**：基于生成的 ID 去重，同一文件重复导入会更新而非重复创建

## 错误提示

导入完成后会显示结果摘要：
- 成功时显示导入数量
- 如果有跳过的记录，可以展开查看每条被跳过的具体原因
- 如果表头包含未知字段，会提示具体是哪些字段

## 文件扩展名

支持 `.csv` 扩展名的文件。
